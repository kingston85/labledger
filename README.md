# LabLedger

Lab data and QA/QC suite for Android, fully offline.

- Sample register with auto IDs, GPS, matrix, preservation, chain of custody and status
- Results with LOD handling, unit conversion and automatic compliance flags against
  WHO drinking-water guideline values or your own limit sets
- Calibration curves: fit, r², LOD/LOQ, back-calculated standards, response →
  concentration with dilution, saved straight to samples
- QC checks (blank, duplicate RPD, matrix spike, CRM/CCV) and Shewhart control
  charts with Westgard rules
- Statistics: descriptives with 95% CI, t-tests (vs limit, Welch, paired),
  one-way ANOVA, Grubbs outlier test
- PDF laboratory test reports, CSV export, full backup
